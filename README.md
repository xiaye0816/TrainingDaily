# 天天打卡 · 体测训练记录

面向家长、老师和学生体测训练场景的 iPhone 原生工具。支持可配置倒计时、语音播报、手动计次、摄像录音、视频数据叠加和保存系统相册。

## 当前能力

- 品牌首页先说明产品用途，再进入单次训练配置。
- 10 秒至 60 分钟倒计时，支持常用时长快捷选择。
- 可配置时间播报间隔、最后 5 秒逐秒播报和到时自动结束。
- 大按钮手动 `+1`、撤销、触感反馈以及可选计次播报。
- 1080p/30fps/SDR 摄像，前后摄像头切换，横竖屏开始录制。
- 正式计时前 3 秒准备，成片自动裁掉准备段。
- 将剩余时间和次数永久写入视频，预览确认后保存到照片。
- 所有配置保存在本机；不包含账号、广告、统计 SDK 或云上传。
- 已包含隐私清单，声明仅使用本 App 自身的 UserDefaults 和计时所需的系统运行时间 API。

## 开发环境

- Xcode 26.6 / iOS 26.5 SDK
- iOS 17.0+
- Swift 5 / SwiftUI
- 可使用 Xcode 自动签名安装真机，也满足当前 TestFlight / App Store 构建工具要求。
