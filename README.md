# 天天打卡 · 体测训练记录

面向家长、老师和学生体测训练场景的 iPhone 原生工具。支持可配置倒计时、语音播报、手动/自动计次、摄像录音、视频数据叠加和保存系统相册。

## 当前能力

- 冷启动由原生品牌启动页无缝衔接 1 秒品牌开屏，随后自动进入单次训练配置。
- 10 秒至 60 分钟倒计时，支持常用时长快捷选择。
- 可配置时间播报间隔、最后 5 秒逐秒播报和到时自动结束。
- 支持仰卧起坐和一分钟跳绳，训练前手动选择项目与手动/自动计次方式。
- 自动计次使用端侧 Vision 人体姿态识别与专项状态机，不上传视频；取景合格并稳定 1 秒后才允许开始。
- 自动模式仍保留“补计 +1”和撤销；人物丢失、多人遮挡或分析性能不足时宁可暂停或降级手动，也不猜测次数。
- 手动模式提供大按钮 `+1`、撤销、触感反馈以及可选计次播报。
- 1080p/30fps/SDR 摄像，前后摄像头切换，横竖屏开始录制。
- 正式计时前 3 秒准备，成片自动裁掉准备段。
- 将剩余时间和次数永久写入视频，预览确认后保存到照片。
- 所有配置保存在本机；不包含账号、广告、统计 SDK 或云上传。
- 已包含隐私清单，声明仅使用本 App 自身的 UserDefaults 和计时所需的系统运行时间 API。
