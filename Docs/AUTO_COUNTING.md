# 自动计次说明与验收

## 支持范围

- 仰卧起坐：手机固定在训练者身体侧面，肩、髋、膝、踝完整可见。
- 一分钟跳绳：手机固定在训练者正面，头顶、双腕、双脚及脚下空间完整可见。
- 自动计次只在录像开启时可选，全部分析在 iPhone 本机完成，原始视频不会上传。
- 验收数据尚未完成前，自动计次只在 Debug 开发包中开放用于实地校准；Release/App Store 构建保持手动计次。
- 首版跳绳统计人体实际跳跃周期，不判断细绳是否每次从脚下通过，也不处理双摇、交叉摇等考试判罚。

## 实时处理链路

相机会话同时输出 1080p/30fps 录像和约 15fps 的分析帧。分析帧在独立串行队列中执行 Vision 2D 人体姿态检测；新帧过晚时直接丢弃，不阻塞录像。系统选择画面中最大且最靠近中心的人，并检查人数、人体完整度、朝向和取景尺寸。

取景条件连续满足 1 秒后才能开始。训练中关键点丢失、多人遮挡或置信度不足会暂停计数，恢复后必须重新经历完整动作周期。两秒窗口内有效分析速度持续低于 12fps 时自动切换为手动计次，录像继续进行。

仰卧起坐状态机按“躺下 → 合格起身 → 回落”计次，并结合归一化躯干角、肩膝距离、迟滞和最短周期抑制抖动。跳绳状态机按“落地 → 起跳 → 腾空 → 落地”计次，联合髋踝垂直位移、速度、双脚同步和手腕运动信号。

所有计次事件使用视频样本的采集时刻，保证次数叠字与动作共享同一时间基准。自动识别、补计 `+1`、撤销和播报沿用同一事件链路。

## 精度门槛

规则状态机和自动化测试已完成，但真实人群精度必须用独立标注数据验证后才能宣称达标：

1. 每个项目至少采集 120 段视频，覆盖至少 30 名不同训练者；儿童视频不得提交 GitHub。
2. 覆盖身高、服装、前后摄像头、横竖屏、光线、速度、停顿、遮挡和不完整动作。
3. 数据按训练者拆分为训练、调参与验收集，不能把同一人的视频随机分散到不同集合。
4. 使用归一化关键点时间序列搜索阈值；规范机位下每段 60 秒验收视频绝对计数误差必须不超过 1 次。
5. 不完整动作、原地晃动、弯腰和人物走动不能产生误计；真机连续运行 5 分钟不能明显拖慢录像或持续增长内存。

如果规则状态机未通过门槛，下一步是训练轻量 Core ML 时序验证器，以归一化姿态序列而不是原始视频作为输入，过滤假动作；未通过验收前不默认开放自动计次。
