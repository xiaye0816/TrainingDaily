# 自动计次说明与验收

## 支持范围

- 仰卧起坐：手机固定在训练者身体侧面，肩、髋、膝、踝完整可见。
- 一分钟跳绳：手机固定在训练者正面，头顶、躯干、双脚及脚下空间完整可见；手腕可见时作为辅助信号，不再因手腕偶发丢失阻止开始。
- 自动计次只在录像开启时可选，全部分析在 iPhone 本机完成，原始视频不会上传。
- 验收数据尚未完成前，自动计次只在 Debug 开发包中开放用于实地校准；Release/App Store 构建保持手动计次。
- 首版跳绳统计人体实际跳跃周期，不判断细绳是否每次从脚下通过，也不处理双摇、交叉摇等考试判罚。

## 实时处理链路

相机会话使用同一组画面样本完成两条链路：Metal/Core Image 在录制时将时间和次数胶囊实时绘制到 720p/30fps H.264 成片，同时以约 15fps 分流给 Vision 2D 人体姿态检测。取消结束后的整段视频重编码，停止时只需完成文件封装。新帧过晚时直接丢弃，不堆积分析任务。系统选择画面中最大且最靠近中心的人，并检查人数、人体完整度、朝向和取景尺寸。后置虚拟多镜头优先启用，取景前可选 0.5×/1×/2× 或双指缩放。

取景准备使用 1.2 秒滚动窗口：累计至少 0.8 秒、8 个样本且有效帧占比不低于 75% 即可开始，避免单帧关键点波动让按钮反复失效。训练中关键点长时间丢失、多人遮挡或置信度不足会暂停计数，恢复后必须重新经历完整动作周期。两秒窗口内有效分析速度持续低于 12fps 时自动切换为手动计次，录像继续进行。

仰卧起坐状态机按“躺下 → 合格起身 → 回落”计次，并结合归一化躯干角、肩膝距离、迟滞和最短周期抑制抖动。跳绳状态机按“落地 → 起跳 → 腾空 → 落地”计次，联合髋踝垂直位移、速度、双脚同步和手腕运动信号。

所有计次事件使用视频样本的采集时刻，保证次数叠字与动作共享同一时间基准。自动识别、补计 `+1`、撤销和播报沿用同一事件链路。

自动计时归零后按配置播放结束提示音，可选温和短哨、清脆短哨、双声哨、柔和提示音或关闭；设置页选择时自动试听，也可反复点击试听。App 保持录像和计次 0.5 秒后封装成片。收尾期的新次数计入成绩和叠字，但不再语音播报；成绩时长仍按配置的考试时长显示。新录像直接以可播放状态写入本地训练记录，旧版未完成任务仍可用原合成器恢复；App 内视频保留 7 天。

次数播报只读数字；常规时间节点读“X 秒”，最后五秒读纯数字。同时触发时使用独立语音实例播放：先开始的语音保持满音量，后开始的语音使用 65% 音量。播报固定使用系统“婷婷”普通话音色。普通麦克风采样原样写入，避免自适应增益和硬削峰带来的电流音；结束提示期间平滑压低麦克风并写入干净的数字提示音，避免现场扬声器回录与数字音轨重复叠加。

结果页和历史详情页可将同一成片多次保存到系统相册；按钮只在单次保存进行时临时禁用。

## 精度门槛

规则状态机和自动化测试已完成，但真实人群精度必须用独立标注数据验证后才能宣称达标：

1. 每个项目至少采集 120 段视频，覆盖至少 30 名不同训练者；儿童视频不得提交 GitHub。
2. 覆盖身高、服装、前后摄像头、横竖屏、光线、速度、停顿、遮挡和不完整动作。
3. 数据按训练者拆分为训练、调参与验收集，不能把同一人的视频随机分散到不同集合。
4. 使用归一化关键点时间序列搜索阈值；规范机位下每段 60 秒验收视频绝对计数误差必须不超过 1 次。
5. 不完整动作、原地晃动、弯腰和人物走动不能产生误计；真机连续运行 5 分钟不能明显拖慢录像或持续增长内存。

如果规则状态机未通过门槛，下一步是训练轻量 Core ML 时序验证器，以归一化姿态序列而不是原始视频作为输入，过滤假动作；未通过验收前不默认开放自动计次。
